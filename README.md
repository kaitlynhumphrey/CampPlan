# CampPlan
A camping trip planner utilizing the BC Parks API.

## File Structure
- html files stored in root directory
- css/ -> contains stylesheets
- js/ -> contains javascript files
- images/ -> contains images
- videos/ -> contains videos

## CSS
Anything used on two or more pages goes in ```general.css```. Everything else goes in ```css/page-name.css```. Colours, spacing dimensions, etc. come from ```variables.css```.

Try to organize rules together by their role. For example, you should style a form and its inputs next to each other. Indicate the start of a new section with a comment.
